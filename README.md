# Counter
A .NET MAUI application for managing counters.

## Features
- Multiple counters support
- Counter interactions such as addition, substraction, reseting, change of color and deletion.
- JSON save system

## Installing
1. Make sure that you have Visual Studio 2022 with .NET MAUI Installed
2. Clone this project in bash<br><br>
   ```bash
   git clone https://github.com/KeneKbee/Counter.git
    ```

## Running
To run the project open the `.sln` file and press `F5`
